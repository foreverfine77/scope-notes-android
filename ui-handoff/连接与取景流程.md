# 连接与取景流程 · 0.27 当前实现

| 状态 | 取景区与操作 | 设备行为 |
| --- | --- | --- |
| 未连接／连接中 | 保留个人封面，拍摄操作不可用 | 请求／等待耳镜 Wi-Fi |
| 已连接未取景 | 显示封面、电量与约计分钟；圆内滑动开始 | 保留网络和电量查询 |
| 实时取景 | 稳向、镜像、耳别、定格；拍照和录像 | 接收实际视频 |
| 收起取景 | 圆内任意方向滑动，回到个人封面 | 停止视频请求，保留连接与电量 |
| 全画幅 | 圆形封面与真实比例矩形之间过渡 | 不改变设备原始视频规格 |
| 录制／保存中 | 开合和切换沿用原生保护 | 等待当前操作结束 |

封面、开合命中区域和取景孔共享几何信息。收起后的灯光反应以设备实测为准，不在离线骨架中承诺。
