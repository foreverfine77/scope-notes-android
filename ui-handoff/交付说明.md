# 微镜记 0.27 · UI 交接包

打开 index.html 查看当前页面骨架、状态、动作和全部提示语。本包以 Android 0.27 的实际代码为基准；中性 HTML 用于审核结构与行为，不是 Android 运行时或设备模拟器。

当前骨架包括：

- 取景页固定为档案／设置／电量、取景窗、稳向／镜像／耳别／定格、状态、相册／快门／录像、设备／连接。封面圆内滑动开合，连接与视频请求分开。
- 设置按护耳档案、个性外观、拍摄与设备、通用、帮助与支持、设备检查排列。
- 档案选择与首页共用圆形首字头像；管理页长按拖动排序，首尾均可插入，浮层圆角完整。
- 镜头封面图库、个人封面裁剪和保存、四种界面主题、操作反馈与设备参考信息。
- 照片详情双图跟手翻页、不足距离回弹、首尾阻尼；张数、日期、耳别及分享／编辑／删除对象同步。
- 30 秒设备检查记录收到的帧率、间隔、电量应答与姿态变化，清晰度和补光由使用者确认。离线骨架的检查结果是明确标注的示例。

深色主题现名「深海星夜」，保留原 scope-dark 偏好键，使用用户提供的深海背景。橙色主题保留偏心背景圆，移除蓝色胶囊；青色操作底板统一绘制两个上圆角。

inventory.json / inventory.js 包含实际资源、引用位置和源码哈希。sourceCommit 是基础提交，工作区修改以 sourceHashes 和 snapshot 为准。references/current-source 保存本轮实际 Java、Manifest、三语言资源及背景和图标。旧包已归档到 references/legacy-before-026，不再作为当前骨架。

新版文案表为 **文案审核-0.27.csv**。原文案审核.csv 被外部程序占用，予以保留，避免打断已有审核。审核结论可导出／导入 review-decisions.json；旧快照的结论需要逐项重新核对。默认展示当前实现文案，不再混入旧版未采用的候选建议。

后续视觉修改请读取 contracts/layout.contract.json、required-icons.json、android-mapping.json，沿用现有动作与录制／保存保护。HTML 不直接运行在 Java Views 中，设计需映射回原生实现。Android 的权限、Wi-Fi 设置与分享窗口属于系统界面。

本地刷新：python tools/build_inventory.py；离线浏览器检查：node tools/qa_browser.mjs。浏览器验证覆盖骨架和审核工具，不能替代 Android 真机验收。安装、操作或录屏手机前，须先确认用户方便使用手机。

设置页背景与相册一致，固定于视口；只有文字与玻璃按钮随内容滚动。
