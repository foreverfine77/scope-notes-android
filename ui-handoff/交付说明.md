# UI 设计交接包

先打开 index.html。它不依赖网络和网页服务器，可以切换手机页面、状态和尺寸，逐项审核按钮、文案与边角问题。

审核台的右侧记录“通过、需要修改、取消、待审核”，可填写候选文本和意见。记录只保存在当前浏览器中，完成一批后导出 review-decisions.json。导入同一份 JSON 可继续审核。快照不同时会提示重新核对。

本包中的灰度骨架和方框图标用于表达位置与语义。定格默认建议放在工具栏首位，另有实际画面左下与当前右上的对照选项，都需要用户确认。当前 App 仍是 0.18，交接包的建议未自动写回 App。

新增「连接与取景流程.md」：连接成功先显示电量和盖板，打开才取景，收起保留网络。页面 capture 的 connected-idle / macro-idle 可演示；灯光联动尚未验证。骨架当前默认页面保留 live 以便直接看按钮位置。

交给 Claude Code 时可直接提供完整目录。在聊天客户端中，按它支持的文件类型提供 ZIP 或解压后的文件，粘贴 CLAUDE_START.txt，并附上已经导出的审核 JSON。Claude 每套风格返回四个接口文件、预览和实现说明。用审核台载入返回的 tokens.json 和 icons.svg，即可在同一骨架上对照。

当前图标来自 ScopeUi 的 Canvas 自绘。SVG 只是此次交接采用的可检查设计源格式，设计质量需要重新审核。常见图标参考 Material Symbols；设备图标和定格图标需要专门设计。

建议把图标用于返回、设置、分享、标注、撤销重做、快门等高频动作。对设备、连接、定格和耳别等容易含糊的语义，保留状态、无障碍名称与长按提示。语言、耳别选项、筛选条件、表单、帮助、错误以及删除确认需要清楚的文字。具体取舍已逐项放在审核台。

完整清单包括三种语言的全部字符串，以及扫描出的中文硬编码和诊断字面量。遗留未引用字符串和诊断信息默认可隐藏，勾选后可继续审核。候选文案只是建议，格式占位符必须保留。隐私事实、反馈链接和需要额外状态的文案应同时核对行为。

也可以在文案审核.csv 中填写审核结论、候选文案和意见，再用 python tools/csv_to_review.py 文案审核.csv review-from-csv.json 转成审核台可导入的 JSON。ID 和源快照列用于对应源码，保持原值。

App 自有 AlertDialog 和 Dialog 可以统一样式。Android 权限、Wi-Fi 网络确认、系统设置、分享面板与外部浏览器属于系统界面。应统一引导、返回、失败与取消路径，不能在主题交付中声称完全接管系统界面。

设计参考使用 Android 可访问性作为工程底线，并结合 Material 3 的图标、内容与对话框规范。主要交互范围至少 48dp；小号文字对比度至少 4.5:1。采用这些规范不要求所有主题使用默认 Android 外观。来源链接位于审核台总览和 inventory.json。

接口文件位于 contracts。tokens.json 的字段与 starter-theme 一致，颜色使用 #RRGGBB，触摸范围至少 48，图标 20–28，旋转反馈保留 180ms。标注色板固定四项。SVG 的 symbol ID 必须与 required-icons.json 完全一致，不能含脚本、字体、图片、外部引用或 CSS。

返回前运行 python tools/check_theme.py 主题目录 --final。这个检查覆盖结构、ID、SVG、尺寸范围与主要对比度，不能代替视觉和 Android 真机回归。原生 Java Views 不能直接运行 HTML/CSS，Codex 需要按 android-mapping.json 做转换与接入。

有 Node 24 和本机 Chrome 时，可运行 node tools/qa_browser.mjs 主题目录。在隔离浏览器中加载返回主题，检查所有页面状态、四种尺寸和审核导出导入。默认 Windows Chrome 路径可用环境变量 SCOPE_CHROME 指定。工具不会连接耳镜，结果不能替代手机验收。

tools/build_inventory.py 可在项目中重新盘点 Android 源码。它会刷新 inventory.json、inventory.js、文案审核.csv 和中性模板的占位图标。Claude 的完成主题应存入独立目录，避免混在 starter-theme。源码、文案和目录规则变化后，旧审核仍可导入，但要重新核对。

需要回交的最小集合为选中的完整主题文件夹、review-decisions.json、关键页面预览和 CODEX_RETURN.txt 中的补充要求。
