你将为 Android App「微镜记 Scope Notes」设计视觉主题。请先读取整个交接包，再开始设计。

项目定位是本地耳镜取景、拍摄、档案、筛选与影像标注。当前 App 使用 Java 原生 Views，图标由 Canvas 绘制。这里的 HTML 是审核骨架和主题对照工具。最终主题将由 Codex 转换到 Android 并跑真机回归。

先读这些文件

1. index.html，可直接打开。查看所有页面、状态、弹窗和边角项。
2. inventory.json，包含当前 0.18 源码快照、动作、完整文案、来源与待审建议。
3. contracts/layout.contract.json，固定槽位、状态与行为边界。
4. contracts/required-icons.json 和 contracts/android-mapping.json。
5. 如果用户提供了 review-decisions.json，先读取审核结论。pending 不是通过。approve 才能作为确定设计依据，revise 要结合用户意见。用户的新指示优先。
6. references/device.png、references/device-phone.png，仅作为耳镜轮廓与设备关系的参考。

第一步先复述你理解的约束与仍待审核的决定，尤其是定格图标和位置。然后生成三套视觉上有明显差异、但共享动作 ID 和页面骨架的主题。可以分别探索深色精密工具感、轻盈浅色和柔和日常风格。不要只换三个主色，应该让层级、轮廓、材质感和图标语言形成差异。

必须覆盖的范围

- 新增用户要求：连接设备与开始取景分开。已连接但未取景时显示电量与预计分钟。建议在圆形或矩形取景窗放盖板，点开开始取景，左侧边缘把手收起；不新增常驻工具栏开关。盖板视觉和把手位置待用户审核。读取 连接与取景流程.md，不把灯光联动画成已验证能力。

- 取景未连接、连接中、实时、重连、定格、微距、旋转放大、录像、保存与失败。
- 相册全部/空相册/空筛选/多选，照片详情，圆形与全画幅录像回放。
- 标注工具、四色、撤销重做、取消与另存副本。
- 档案切换和表单、语言、耳别、年份月份、微距说明、设备发现。
- 使用帮助、隐私说明、反馈说明、诊断与删除确认。
- App 自有 AlertDialog 需要同一视觉系统。系统权限、Wi-Fi 确认、系统设置和系统分享属于系统边界，设计前后引导即可。

需要重点重新设计的图标

- 设备搜索与连接。设备搜索参考用户给的细长耳镜轮廓，可以旋转或抽象，避免和普通手机、遥控器、牙刷混淆。设备搜索、连接、取消连接和断开要能区分。
- 定格与恢复实时。用户不喜欢使用播放/暂停。请给画框或图像检查语义的方案，并在图标板中放大对比。骨架中工具栏首位、实际画面左下和当前右上都是待审选项。
- 其他图标统一光学尺寸、线宽、圆角与选中状态。常见图标可参考 Material Symbols，但不能把不同风格资源混拼。
- 用户明确喜欢当前旋转放大按钮的反馈动画。保留顺时针 90°、180ms 动画和实际画面内部右下角跟随，不擅自换成普通网页全屏动作。

不要自动改写业务行为

- 连接状态变化不能使底部固定操作位置跳动。
- 标注始终另存副本，保留原图；录制和保存保护继续有效。
- 不添加未验证的硬件能力，不重新加入已撤下的左右耳对照和文字备注。
- 只保留四个标注颜色。更改颜色值、位置、文案、返回规则或退出确认时写进 design-decisions.json，等待用户审核。
- 现有帮助包含过时的对照描述。使用 inventory.json 中的候选文案和用户审核，不把候选直接当成已批准。

每套主题必须交付一个完整文件夹

tokens.json
icons.svg
manifest.json
design-decisions.json
preview/ 下的关键页面预览
implementation-notes.md

从 starter-theme 克隆格式。字段名称、语义图标 ID 与文件名保持一致。将 placeholderIcons 改为 false。SVG 使用每个 symbol 独立的 viewBox="0 0 24 24"，仅包含静态路径或几何图形，采用 currentColor。不要引入脚本、外部引用、位图、字体或网页 CDN。每个必需图标都要重绘；模板方框只是占位。

implementation-notes.md 要写明哪些设计是已批准的，哪些是你的建议，哪些需要原生 Android 额外实现。不要承诺 CSS 可以直接装进当前原生 App。

最后运行

python tools/check_theme.py 你的主题文件夹 --final

然后把 tokens.json 和 icons.svg 载入 index.html 的“载入 Claude 主题”，用同一组页面和状态比较。确保 360×800、390×844、412×915、横屏、长文、长英文、繁体和字体放大都经过检查。提供每套主题的设备搜索、定格和旋转图标放大板，以及帮助/耳别/删除确认的统一样式预览。

交回整个主题文件夹及用户审核 JSON。完成视觉设计后由用户选择，再交 Codex 集成与手机回归。
