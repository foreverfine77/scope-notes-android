# 微镜记 · 橙色线条风格说明（交给 GPT / Codex）

## 使用前提
- 参考对象是一款冥想 App 的截图。借用它的风格语言：暖橙与蛋黄、奶油纸底、深棕轮廓线、扁平拟物小插画、蓝色与珊瑚色点缀。不要复制它的“罐头”角色、房屋剪影或图标原稿。
- 页面骨架、固定槽位、状态、动作 ID、返回规则一律不改，以 `contracts/layout.contract.json` 为准。本说明只改视觉。
- 配套的 `微镜记-橙色线条风格示例.html` 是视觉参照，不是可直接装进 Android 的代码。

## 一句话
奶油色纸面上，所有元素都有一圈深棕轮廓线，像贴纸或线稿；暖橙只用来烘托镜头，蛋黄用来标记主操作。

装饰色（只用于插画、背景圆、缩略图占位）：日橙 #F6A04D、天蓝 #8EC9E8、珊瑚 #F4907B、夜蓝 #3F4B7A。轮廓线的细分隔线色 #E3D3B8 仅用于虚线和次要分隔。标注页的四色保持原值，装饰色不进入标注色板。

可读性要求：日橙 #F6A04D 只作背景圆和快门内芯，上面不放文字；白色文字不放在橙色或蛋黄上。

形状与尺寸：radii button 999（胶囊与圆形）、panel 24、sheet 30；borderWidth 2；触摸范围 48；图标 22–24；页面边距 14–16。
效果：surfaceOpacity 1；不使用柔和模糊阴影，只允许“硬阴影”（向下偏移 3–4dp、颜色同轮廓线、无模糊），且仅用于主操作、快门和镜头，避免整屏发黑。

## 材质与层级
1. 一张奶油纸面，不再分上下两块面板。取景窗后面放一轮大号日橙圆（像日出），圆形有轮廓线；两三朵天蓝描边云点缀，数量不增加。
2. 所有按钮、胶囊、弹窗、列表行都有 2dp 棕墨轮廓，白色填充；选中态改蛋黄填充，轮廓不变。
3. 主操作只用蛋黄胶囊加硬阴影（“开始取景”），同一屏最多一个。其他一律白色加轮廓。
4. 弹窗是顶部带 2dp 轮廓的圆角面板，选项是一行行带轮廓的圆角卡片，选中行蛋黄填充并打勾，取消是白色轮廓胶囊。

## 字体
- 使用系统中文字体，不引入网络字体。标题 20–22sp，字重 800；按钮与标签 13–16sp，字重 700；说明 11–12sp，字重 600–700。

## 图标语言
- 棕墨单线描边，线宽 2，圆头圆角，与轮廓线同色同粗；同一 24×24 网格、同样的光学大小，不混用其他风格的资源。
- 图标放进白色轮廓圆；选中时圆填蛋黄，图标仍为棕墨。
- 定格：画框四个角加中心圆点，表示“检查画面”，不用播放或暂停。稳向：圆内向上箭头。镜像：中线加两个三角。标记：铅笔。
- 设备搜索：细长耳镜斜放，头部为圆。连接与断开：链环，取消连接用链环加“取消”文字，不与搜索混淆。
- 旋转放大按钮：保留顺时针 90°、180ms、画面内右下角锚定，换成白色轮廓圆。
- 快门：外环棕墨，内芯日橙，内芯带轮廓和硬阴影。

## 盖板
- 已连接未取景时，取景窗被浅黄 #FDE7B8 盖板覆盖，带两圈棕墨线同心环（外圈实线，内圈虚线），中间一个蛋黄“开始取景”胶囊，下面两行小字说明电量仍可查看。
- 点开后盖板淡出，约 160ms；开启“减少动态”时直接切换。
- 灯光联动未验证，盖板不要表现成关灯。

## 空状态与插画
- 线稿加扁平色块，描边与图标同色同粗，用装饰色填充。画自家物件（镜头、耳镜、取景环、日出），不借用其他 App 的角色。
- 一句话说明加一个明确动作，不写“暂无内容”这类道歉式文案。

## 不要做
- 不改骨架、槽位、状态和动作 ID；不增加未验证的硬件能力；不重新加入左右耳对照和文字备注。
- 不在日橙或蛋黄上放白字；不用模糊阴影、渐变（相册缩略图占位除外）；不把硬阴影加到每个元素上。
- 不把 CSS 效果当成可直接装进原生 Java Views 的代码。

## 需要原生 Android 额外实现
- 2dp 轮廓线与硬阴影需要自绘背景（描边加偏移的实心底），旧系统需要真机回归。
- 取景窗后的日橙圆和云朵放在取景区后面，不得遮挡或缩小镜头；在 360×800、390×844、412×915 和横屏下检查。
- 盖板的同心环、空状态插画做成 VectorDrawable。
- 对比度、48dp 触摸范围和字体放大需要用真机检查。
