# 微镜记 · 清爽青色风格说明（交给 GPT / Codex）

## 使用前提
- 参考对象是 Waterllama 的截图。借用它的风格语言：饱和青色、大圆角白色底部面板、深蓝胶囊主按钮、粗圆体标题、扁平活泼的插画。不要复制它的羊驼等角色和图标原稿。
- 页面骨架、固定槽位、状态、动作 ID、返回规则一律不改，以 `contracts/layout.contract.json` 为准。本说明只改视觉。
- 配套的 `微镜记-清爽青色风格示例.html` 是视觉参照，不是可直接装进 Android 的代码。

## 一句话
明亮、友好的青色工具：上半屏是青色背景加深色镜头，下半屏是白色圆角操作面板，主操作只有一个深蓝胶囊。

tokens.json 目前没有“品牌青色”字段。建议在 design-decisions.json 的 layoutChanges 之外另记一条视觉提案：新增可选字段 `hero: #12B6D6`（取景页上半屏背景）和 `heroDeep: #0A6E85`（录像中的深青背景）。在字段获批之前，实现时可作为主题私有常量。
点缀色只用于相册缩略图占位、空状态插画和筛选标签：珊瑚 #FF7A6B、日黄 #FFC93C、草绿 #6FCF5B、紫 #8E6BD8。注意标注页的四色保持原值，点缀色不要进入标注色板，避免混淆。

可读性要求：白色文字不能直接放在主青 #12B6D6 上做小字（对比度约 2.3:1）。青色背景上只放大号标题和图标，电量、状态文字一律放进白色胶囊或白色面板。

形状与尺寸：radii button 999（胶囊与圆形）、panel 24、sheet 32；触摸范围 48；图标 22–24；页面边距 14–18。效果：surfaceOpacity 1，borderWidth 0，基本不用阴影，靠色块区分层级。

## 材质与层级
1. 取景页：上半屏青色，镜头是深色圆（或矩形）并带 6dp 白色描边，像贴纸；下半屏白色面板，顶部圆角 32，包含工具、状态行、快门行和设备行，顺序与骨架一致。
2. 内容页（相册、设置、帮助、标注）使用浅底 #F3F9FA，顶部不铺大块青色，避免长文字落在青色上。
3. 弹窗是白色大圆角底部面板，右上有灰色圆形关闭按钮，标题居中粗体。
4. 主操作（“开始取景”“完成”）只用墨蓝胶囊，同一屏最多一个。次要操作用浅青胶囊。

## 字体
- 使用系统中文字体，不引入网络字体。标题 20–22sp，字重 800；按钮与标签 13–16sp，字重 700；说明 11–12sp，字重 600。
- 如果系统有圆体风格的字体，可作为可选项，但不能依赖。

## 图标语言
- 单线描边，线宽 2，圆头圆角，比暖纸风格略粗；同一 24×24 网格、同样的光学大小，不混用其他风格的资源。
- 工具图标放进浅色圆形按钮；选中时整个圆变墨蓝，图标变白。
- 定格：画框四个角加中心圆点，表示“检查画面”，不用播放或暂停。稳向：圆内向上箭头。镜像：中线加两个三角。标记：铅笔。
- 设备搜索：细长耳镜斜放，头部为圆。连接与断开：链环，取消连接用链环加“取消”文字，不与搜索混淆。
- 旋转放大按钮：保留顺时针 90°、180ms、画面内右下角锚定，换成白色圆底。
- 快门：外环墨蓝，内部实心主青圆。相册入口用缩略图占位（无图时用日黄到珊瑚的柔和渐变方块）。

## 盖板：睡着的镜头
- 已连接未取景时，取景窗被浅青盖板覆盖，中间是两条闭合的弯眼线，像睡着的镜头，下面是墨蓝“开始取景”胶囊，再下面两行小字说明电量仍可查看。
- 点开后眼睛睁开并进入实时画面；动效约 160ms，开启“减少动态”时直接切换。
- 灯光联动未验证，盖板不要表现成关灯。

## 空状态与插画
- 插画是扁平、圆润、带一点表情的自家物件（镜头、耳镜、取景环），颜色取自点缀色，不借用其他 App 的角色。
- 一句话说明加一个明确动作，不写“暂无内容”这类道歉式文案。

## 不要做
- 不改骨架、槽位、状态和动作 ID；不增加未验证的硬件能力；不重新加入左右耳对照和文字备注。
- 青色背景上不放小号白字；不在内容页铺大面积青色；不把点缀色用作标注色。
- 不把 CSS 效果当成可直接装进原生 Java Views 的代码。

## 需要原生 Android 额外实现
- 镜头的白色描边、盖板的闭眼图案需要自绘或矢量资源。
- 上半屏青色与下半屏白色面板的圆角衔接，需要在不同屏幕高度（360×800、390×844、412×915、横屏）下检查，面板不能压住取景窗。
- 相册占位渐变和空状态插画做成 VectorDrawable。
- 对比度、48dp 触摸范围和字体放大需要用真机检查。

## 给 GPT 的提示语
请读取本说明和示例 HTML，把风格套到现有 UI 骨架上，不要修改骨架、槽位、状态和动作 ID。先把色板、圆角填入 tokens.json（hero 与 heroDeep 作为提案另记），再按“图标语言”重绘 icons.svg，然后对照示例逐页检查：实时取景、已连接未取景盖板、耳别弹窗，之后是相册、标注、档案、帮助和删除确认。所有位置、文案或返回规则的改动写进 design-decisions.json，等待我审核。完成后运行 `python tools/check_theme.py 主题目录 --final`，并说明哪些部分需要原生 Android 额外实现。
