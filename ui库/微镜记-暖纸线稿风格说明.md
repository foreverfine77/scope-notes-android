# 微镜记 · 暖纸线稿风格说明（交给 GPT / Codex）

## 使用前提
- 参考对象是 Dtd Sounds 的截图。借用它的风格语言：暖纸底、细线条、圆形白按钮、柔和阴影、陶土色主按钮、深色内容面板。不要复制它的猫、三角角色等插画或图标原稿。
- 页面骨架、固定槽位、状态、动作 ID、返回规则一律不改，以 `contracts/layout.contract.json` 为准。本说明只改视觉。
- 配套的 `微镜记-暖纸线稿风格示例.html` 是视觉参照，不是可直接装进 Android 的代码。

## 一句话
像一本放在桌上的暖色纸质记录本：纸底、细墨线、圆润白色按钮，只有取景窗是深色，让镜头画面成为唯一最深的区域。

形状与尺寸（对应 tokens.json）：radii button 16、panel 26、sheet 28；触摸范围 48；图标 22–24；页面边距 14–16。
效果：背景纯色，surfaceOpacity 1，borderWidth 0（用阴影而不是描边区分层级），阴影为柔和的暖色小阴影，约 `0 2dp 8dp` 暖棕色 10% 不透明度。

## 材质与层级
1. 三层：纸底，白色按钮与卡片，深色取景窗。不再增加第四层。
2. 层级靠阴影和色差，不靠描边。取景垫是比纸底略深的圆角面，不画虚线。
3. 所有圆形按钮同一套阴影；选中态不加阴影，改用 accentSoft 底加 accent 线条色。
4. 主操作只有一个陶土色实心按钮（“开始取景”），其他全部为白色按钮。快门是双环：外环墨线，内部白色圆。

## 图标语言
- 单线描边，线宽 1.6，圆头圆角，无填充；唯一允许实心的是录像图标中心的小圆点。
- 全部使用同一个 24×24 网格、同样的光学大小，不混用其他风格的资源。
- 圆形白按钮内放图标；工具栏按钮下方保留 11sp 文字标签（骨架里本来有标签）。
- 定格：画框四个角加中心圆点，表示“检查画面”，不用播放或暂停。
- 稳向：圆内向上箭头。镜像：中线加两个三角。标记：铅笔。相册：圆角相框加山形。
- 设备搜索：细长耳镜斜放，头部为圆。连接和断开：链环；取消连接用同一个链环加“取消”文字，不与搜索混淆。
- 旋转放大按钮：保留顺时针 90°、180ms、画面内右下角锚定，只换成白色半透明圆底。

## 取景页与盖板
- 取景窗是圆形或矩形的深色面，外面一圈取景垫。收起把手在取景垫左缘，细小的圆角竖条。
- 已连接未取景时，取景窗被暖白色盖板覆盖：细墨线同心环，中间一个陶土色“开始取景”按钮，下方两行小字说明电量仍可查看。盖板下方的工具和录像按钮降低透明度。
- 灯光联动未验证，盖板不要画成“关灯”的效果。

## 弹窗与列表
- 底部弹窗：顶部小横条，大圆角卡片，标题居中。
- 选项做成一个分组列表，细分隔线隔开，选中项文字用 accent，右侧打勾。不要把每个选项做成独立按钮。
- 取消是弹窗下方单独一张整宽白色圆角卡片。
- 其他 App 自有对话框沿用同样的卡片、圆角和按钮样式。系统权限、Wi-Fi 确认和分享面板属于系统界面，不要声称可以接管。

## 字体
- 使用系统中文字体，不引入网络字体。标题 17–18sp 半粗，正文 14–15sp，说明 11–12sp。
- 数字、电量可用等宽数字（tabular）避免跳动。

## 空状态与插画
- 空相册等空状态用单线线稿，墨线色，线宽与图标一致，可点缀一点夜蓝或小黄点。线稿画耳镜、取景环等自家物件，不要借用其他 App 的角色。
- 一句话说明加一个明确动作，不写“暂无内容”这类道歉式文案。

## 动效
- 保留现有旋转反馈。盖板掀开用轻微位移加淡出，约 160ms；开启“减少动态”时直接切换。

## 不要做
- 不改骨架、槽位、状态和动作 ID；不增加未验证的硬件能力；不重新加入左右耳对照和文字备注。
- 不用渐变、霓虹或大面积彩色；不用纯黑和纯白；不用描边区分按钮。
- 不把 CSS 效果当成可直接装进原生 Java Views 的代码。

## 需要原生 Android 额外实现
- 取景垫、盖板的细环和同心圆需要自绘或矢量资源。
- 柔和阴影用 elevation 或自绘阴影，旧系统上效果会有差异，需要真机回归。
- 分组列表的圆角分割需要自定义背景。
- 线稿插画做成 VectorDrawable。
- 对比度与 48dp 触摸范围用真机和字体放大检查。

## 给 GPT 的提示语
